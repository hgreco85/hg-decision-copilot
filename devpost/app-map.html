HG Decision Copilot — App Map

One offline page. You paste text, and plain JavaScript turns it into tasks, then duplicates, priorities and abandoned alerts. Nothing leaves the browser. Built at commit 0d8d04d.

How it fits together

Route through the code

1. src/parser.js › parseLine: reads one messy line. It pulls out the agent prefix, the date, key: value fields and status words. Anything not found stays null.
2. src/dedup.js › tokenize then findDuplicates: normalizes words (accents, stopwords, generic verbs, ES→EN CANON map), scores every pair with Jaccard, and groups pairs with union-find. A pair needs a score of at least 0.6 and at least 2 shared words.
3. src/prioritize.js › scoreTask: averages only the criteria that are present and reports the missing ones. With no criteria the score is null.

To change this, start here

  • How strict duplicate matching is: findDuplicates(tasks, { threshold, minShared }) in src/dedup.js.
  • Words that should match across languages: CANON in src/dedup.js. Words to ignore: STOP.
  • Priority weights: WEIGHTS in src/prioritize.js.
  • Default abandoned days: checkAbandoned in src/abandoned.js and the #days input in index.html.
  • CSV columns: toCSV in src/export.js.

A practice to reuse

Write the negative tests before you tune a matcher. Here, the login/logout and "same verb, different object" cases in tests/dedup.test.js showed that lowering the threshold was the wrong fix, so the cross-language word map was the safe one.

Run it

Double-click index.html, or open it with ?demo=1 to auto-load the sample. Run the tests with node --test tests/.
